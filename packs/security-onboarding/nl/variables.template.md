# Variabelen

Kopieer dit bestand naar `variables.md` in dezelfde map en vervang elke waarde door die van je organisatie. `variables.md` is specifiek voor deze installatie en wordt niet met het pack meegenomen.

- `{{security_email}}`: security@example.com
- `{{help_channel}}`: #security-help
- `{{tier_public}}`: Openbaar
- `{{tier_internal}}`: Intern
- `{{tier_confidential}}`: Vertrouwelijk
- `{{tier_restricted}}`: Geheim
