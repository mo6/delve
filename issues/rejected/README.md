# Rejected issues

Issues that were considered and turned down without being built. They live here so the
decision is findable later, rather than lost in a closed discussion or a deleted branch.

A rejected issue:

- sets `status: rejected` in front matter and records why in the optional `reason:` field;
- keeps its `DELVE-NNNN` id (the id sequence is shared across root, `archive/`, and `rejected/`);
- leaves `commits:` empty, since nothing shipped;
- may set `supersedes` / `related` to link the issue that won instead.
